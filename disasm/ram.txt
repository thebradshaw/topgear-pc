# Work RAM variables: <addr> <name> [; comment]. 0000-1FFF is low RAM (mirrored in banks 00-3F/80-BF).
# The menus and races use the same low addresses for different things; such entries are
# written Menu<name>/Race<name>.
0000 NmiTrampoline ; JML: $0F:8000 in menus, $00:EC1A in races
0004 IrqTrampoline ; RTI in menus, JML $00:EC5B in races
0008 MenuFrameCounter8/Race08 ; menus: incremented every NMI; races: a code pointer ($B75A at start)
000A MenuJoy1Held/RaceIrqHandler ; races: routine the raster IRQ calls via JSR ($000A)
000C MenuJoy2Held
000E MenuJoy1Pressed ; newly pressed buttons, accumulated until the game clears them
0010 MenuJoy2Pressed/RaceJoy1Held
0012 RaceJoy2Held
0014 RaceJoy1Pressed
0016 RaceJoy2Pressed
0023 DecompSrc ; 24-bit source pointer for DecompressBegin/Next
0042 MenuInidispShadow ; written to INIDISP ($2100) every menu NMI
0424 MenuNmiDmaChannels ; DMA channel mask started by the menu NMI handler, then cleared
1F06 CarTypeIndex
1F86 Player1Name ; 8 characters, blank = spaces
1FA3 Player2Name
1FF6 WarmBootFlag
1FFC FrameCounter16 ; incremented every menu NMI, survives soft reset
